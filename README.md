# SOUMaterial Website

Simple static website for **SOUMaterial**, a Silver Oak University resource portal for **MCA** and **BCA (Hons.)** semester-wise material.

## Features
- Light/Dark theme switcher in the top-right corner.
- Semester-wise material sections for MCA and BCA (Hons.).
- Toggle button to show/hide class timings and timetable.
- Responsive layout for desktop and mobile.

## Run locally
Open `index.html` directly in your browser.
